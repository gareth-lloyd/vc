# Critique — 2026-05-27

Four parallel review agents critically assessed every ticket in this
folder against the current `django_res/` codebase. This file records
the synthesis. INDEX.md was updated to reflect status changes.

## Summary of changes

**Dropped** (3) — premise false or framing-only:

- **FG-003** — `Property.group` is non-nullable; the "null group" case
  is schema-impossible.
- **SMELL-005** — verified: no residual `Property.country` free-text
  field. CLAUDE.md note was a Canary-project convention.
- **GAP-003** — meta framing, not a ticket. The ticket itself
  acknowledges this. Per-journey tickets supersede it.

**Closed with finding** (4) — investigations resolved by reading the
code:

- **INV-001** — `PropertyContactAssignment` has the right shape: two
  partial unique constraints; "primary owner per property" enforced via
  `is_primary`.
- **INV-002** — `pick_rule_for_night` orders by `priority` desc then
  `rule_specificity`; both branches pinned by tests.
- **INV-003** — Convention is partition-by-purpose, not signed sum;
  REFUND never mixes into DEPOSIT/BALANCE aggregates.
- **INV-005** — `legacy_id = CharField(max_length=64, null=True,
  blank=True, db_index=True)` consistent across ~30 models; all loaders
  key on it.

**Resolved by design docs** (4) — questions already answered in
`product-design/10-decisions.md`:

- **Q-003** — Channel-manager integrations: out of v1.
- **Q-004** — Hold-duration shape: per-villa default + per-hold
  override via `PropertySettings.hold_duration_hours`. Numeric default
  still TBD.
- **Q-009** — Single public site for v1.
- **Q-011** — System default → site only (no per-property override).

**Needs revision before implementing** (5):

- **BUG-005** — Proposed trigger fix is heavier than needed. Prefer
  sweeper-authoritative + opportunistic expire of overlapping holds in
  the same transaction.
- **BUG-007** — The load-bearing fix claim is **wrong**: `pre_save`
  does not fire on `bulk_create`. Real options: override
  `Manager.bulk_create`, mandate a loader-level helper, or switch to a
  Postgres `SEQUENCE` per anchor.
- **FG-001** — Drop the "silent corruption" framing — currency mismatch
  raises `NoRateAvailable`, not silent corruption. Service-layer parity
  assertion is sufficient; no denormalised `quotation_currency_id`.
- **FG-005** — Resolve whether `IdempotencyRecord` is dead code (live
  contract is `meta["idempotency_key"]` via `core/idempotency.py`)
  before redesigning the schema.
- **Q-001** — Partially answered (single `cancellation_window_days`
  committed). Re-scope to "bands in v1?"
- **Q-014** — Split audit retention vs PII retention; they're different
  decisions.

**Promotions / demotions** (4) — severity moves to apply on next pass:

- **FG-006** → **🔴 bug**: lost-update race on dates/balance under READ
  COMMITTED is a real correctness bug.
- **FG-008** → **🔴 bug**: no `Property.timezone` breaks every wall-clock
  reminder outside Europe/London.
- **SMELL-006** → **🟠 footgun**: required field with no service-level
  guard fails opaquely at the API surface.
- **FG-002** → 🟡 smell; **FG-007** → 🟡 smell (low real-world risk
  today).
